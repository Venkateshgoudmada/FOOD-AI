# Food AI Agent

A simple AI-powered Food Assistant built with Python and OpenAI.

## Features

- Recipe recommendations
- Healthy meal suggestions
- Cooking tips
- Ingredient-based food ideas
- Flask web interface

## Installation

```bash
pip install -r requirements.txt
```

## Setup

Rename `.env.example` to `.env` and add your OpenAI API key.

```env
OPENAI_API_KEY=your_api_key_here
```

## Run CLI Version

```bash
python food_agent.py
```

## Run Flask Web App

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
